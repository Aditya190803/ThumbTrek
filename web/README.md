# ThumbTrek site (Vercel)

Static marketing site for ThumbTrek.

## Deploy on Vercel

1. Import the GitHub repo in [Vercel](https://vercel.com/new).
2. Set **Root Directory** to `web`.
3. Framework preset: **Other** (no build command).
4. Output directory: `.` (or leave blank — `vercel.json` already points at this folder).
5. Deploy.

Or from this folder:

```bash
npx vercel --yes
```

The download CTA points at `https://github.com/Aditya190803/ThumbTrek/releases/latest`.
