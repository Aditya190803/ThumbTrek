This deployment has no Firebase config

The dashboard reads your account from Firebase, and this copy of the site has not been pointed at a project yet. Nothing is broken — the file just is not there.

Copy web/app/firebase-config.example.js to web/app/firebase-config.js, fill in the six values from the Firebase console, and redeploy. web/README.md says which console screen produces each one, and why that file is safe to commit.
